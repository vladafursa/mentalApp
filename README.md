# Your Mental Health Assistant (iOS App)

**A production‑ready iOS application for mental wellbeing tracking, designed to help users privately log emotions, reflect on their mood, and build healthier habits.**
---
## Overview

Lack of support and access to it, bad quality of it, fear of opening up, feeling helpless and lost – all these problems require a solution. Sometimes even a little talk can prevent person from committing suicide and simply improve overall wellbeing. The solution to this problem can be an IOS application “Your mental health assistant” that provides track of user’s wellbeing. An app is a good choice as “health and lifestyle” category is considered the most popular mobile app category among others worldwide (Statista 2017), so it will bring attention among users. Moreover, the app is a self-tracker, so the user will not need any interactions with others, it will help to avoid shame and increase openness. The app is done with authentication, so the user will not need to be stressed about somebody else knowing personal notes inside the app. 
While the app does not carry any medical approach, there are contact details of a helpline for emergency situations.

---
##  Features

- **Authentication & privacy**: Protected user login ensures notes remain private; restricted to adult users.  
- **Emergency support**: Quick access to helpline contact details.
- **Private journaling**: A secure text field to express feelings openly, without fear of judgment.  
- **Mood tracking & calendar**: Daily happiness ratings, journal entries, and photos stored in a personal calendar.  
- **Interactive statistics**: Visualise mood trends over time with a chart.  
- **Export to PDF**: Download your calendar entries (text, ratings, photos) for offline review.  
- **Notifications**: Gentle daily reminders to log emotions and maintain consistency.  
- **Selfie gallery**: Organized collection of daily selfies for self‑reflection.  
- **Supportive alerts**: Automatic encouragement when low mood ratings are detected.  
- **Mindfulness activities**: guided “mental walks”.

##  Tech Stack
- **Languages & Frameworks**: Swift, SwiftUI, Foundation, Combine, UIKit  
- **iOS APIs**: CoreLocation, AVFoundation, UserNotifications, Charts, MapKit  
- **Cloud Services**: Firebase (Auth, Firestore, Messaging), Google Maps SDK  
- **Architecture**: MVVM with strong UX focus  
- **Tools**: Xcode
